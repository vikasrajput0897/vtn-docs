# Step 3: OpenID Connect (OIDC) Setup Guide

OpenID Connect (OIDC) is an identity layer built on top of the OAuth 2.0 protocol, ideal for modern cloud identity providers.

---

## 1. Accessing OIDC Setup

1. In VoiceToNotes, go to **Settings > Single Sign-On**.
2. Click **Configure SSO** on your verified domain card.
3. Select **OIDC** on the protocol selector.

---

## 2. Configuration Fields

Fill in the following three fields provided by your Identity Provider:

| Field | Requirement | Description & Example |
| :--- | :--- | :--- |
| **Client ID** | Required | The Application / Client ID assigned to VoiceToNotes in your IdP. <br>`7d8f9214-3c1a-4d92-9e81-e23485ab9012` |
| **Client Secret** | Recommended | The confidential secret string generated by your IdP. It is masked for security. |
| **Issuer / Discovery URL** | Required | The HTTPS base URL serving the OpenID discovery document (`/.well-known/openid-configuration`). <br>`https://login.microsoftonline.com/<tenant-id>/v2.0` or `https://acme.okta.com` |

---

## 3. Redirect URI / Callback URL

When creating your OIDC app registration in your Identity Provider (e.g., Azure AD App Registrations or Okta OIDC App), supply the VoiceToNotes Redirect URI:

```text
https://vtnaiproject.firebaseapp.com/__/auth/handler
```

---

## 4. Saving the Configuration

Click **[ Configure SSO ]** at the bottom of the form. VoiceToNotes validates the OpenID Discovery endpoint and saves the credentials securely.
